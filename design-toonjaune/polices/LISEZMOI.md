# Polices

| Famille | Rôle | Licence |
|---|---|---|
| **Atma** | mot accentué des titres | SIL Open Font License — **libre**, redistribuable |
| **Kefir** | titres | **commerciale** — vérifiez vos droits avant tout usage |
| **Rebond Grotesque** | texte et interface | **commerciale** — idem |

Kefir et Rebond Grotesque proviennent d'un thème Shopify sous licence. Elles sont
là pour que la démo s'affiche fidèlement, **pas** pour être redistribuées.

Pour les remplacer : une seule ligne dans `systeme/jetons.css`.

```css
--titre:  "Votre police", sans-serif;
--texte:  "Votre police", sans-serif;
```

Substituts libres proches : **Fredoka** ou **Baloo 2** pour Kefir,
**Inter** ou **Manrope** pour Rebond Grotesque.
